PL CHAT Desktop Package

How to open:
1. Extract the ZIP file.
2. Open index.html with Chrome, Edge, Safari, or Firefox.
3. Sign up with your email.
4. Verify your account using the email verification flow configured for PL CHAT.
5. Log in and use chat, feed, dashboard, profile, file sharing, language tools, and ChatGPT Assistant.

Notes:
- The production PL CHAT workspace should use the server-backed email flow, SMTP, and a real HTTPS public URL.
- Language files are UTF-8 and should render Thai, Chinese, English, and other languages correctly.
- Profile and room names in this package are saved locally by the browser. The production system should use the server database.
- ChatGPT Assistant requires the backend assistant service with OPENAI_API_KEY set on the server side.
